# Contributing to gogit

Welcome! We're excited that you want to contribute to `gogit`. Here's a quick guide to help you get started.

## How to Contribute

### 1. Reporting Bugs

- Search existing issues to see if the bug has already been reported.
- If not, create a new issue using the **Bug Report** template.
- Provide a clear description and steps to reproduce.

### 2. Suggesting Features

- We love new ideas! Check the existing feature requests first.
- Use the **Feature Request** template to explain your idea.

### 3. Submitting Pull Requests

- Fork the repository and create your branch from `dev`.
- Ensure your code follows the existing style (run `cargo fmt`).
- Write clear commit messages (or use `gogit` to help!).
- Reference any related issues in your PR description.

## 🏷️ Good First Issues

If you're looking for a place to start, look for issues labeled `good-first-issue`. Common starter tasks include:

- Adding support for more project file types in `gogit explain`.
- Improving TUI colors or animations.
- Adding documentation for specific subcommands.
- Writing unit tests for helper functions.

## Development Setup

```bash
git clone https://github.com/buka-pitch/gogit.git
cd gogit
cargo build
```
